# othello-sim

CIRCUIT OTHELLO EVOLUTION の学習パイプライン。
個性を持つオセロAIが世代を重ね、いずれ最強の壁（タイトルホルダー）に挑む。

将棋版（shogi-sim）と違い、外部エンジン（やねうら王）への依存がない。
探索・評価関数はすべて自前のPythonコードで完結する。

## 構成
```
othello_sim/
  board.py       盤面管理・ルール
  engine.py      評価関数・ミニマックス探索
  individual.py  個体定義（角・機動力・安定石・石数の重みが個性）
  elo.py         Eloレーティング計算
  evolution.py   進化ロジック（スイス方式トーナメント・変異・移民交配・タイトル挑戦）
  family_names.py 血統名生成
  io_utils.py    チェックポイント読み書き
  play.py        対局処理
run_evolution.py メイン実行スクリプト
```

## 設計の要点
- 個体はA流1系統からスタートする
- 通常世代は「無性生殖」：生存者の変異クローンで次世代の枠を埋める（尖った個性が育ちやすい）
- 定期的に移民が現れ、既存の実力者と交配（ブレンド）してハイブリッドが生まれる（尖りを均す役割）
- ベンチマーク（温度計）：首位の勝率に応じて自動で強さが上がる壁。Eloには影響しない
- タイトル挑戦：温度計の壁を極限まで登り切った首位だけが、タイトルホルダー（暫定・将来的に本物のEdaxへ差し替え予定）に挑戦できる

## ローカル実行
```bash
python run_evolution.py --data-dir data --generations 3 \
  --population-size 16 --swiss-rounds 4 --search-depth 4 \
  --benchmark-depth 5 --benchmark-games 5
```

## 既知の制約（今後の課題）
- 探索エンジンは分かりやすさ優先で、高速化（置換表・ビットボード等）を行っていない
- そのため探索深さ8以上は非現実的に重い。現状はベンチマーク上限を深さ6、タイトルホルダーを深さ7に抑えている
- 本物のEdaxとの接続はまだ行っていない（タイトルホルダーは暫定的に自前の深い探索で代用）
